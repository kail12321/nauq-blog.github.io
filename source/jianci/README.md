# 简词 JianCi · 背单词应用

一个只用 HTML / CSS / JavaScript 写的**离线背单词应用**：双击 `index.html` 就能用，不需要安装、不需要联网、不需要构建，学习记录存在浏览器本地。

支持 **考研 / 六级 / 雅思** 三本词书（也可以导入自己的 txt 词表），按 **艾宾浩斯记忆曲线** 自动安排每天的复习，自带 **例句、形近词、词形变化、词根词缀**，并在每天最后用 **单词填空** 巩固当天所学。

---

## 快速开始

1. 双击 `index.html`（或双击 `open.bat`）。
2. 首次进入默认选中《考研核心词汇》，每日 20 个新词。
3. 按「今日任务」从上往下走：

   **学新词 → 复习到期词 → 末尾单词填空 → 打卡**

> 若刷新后进度丢失，说明你的浏览器禁止了 `file://` 页面的本地存储。此时改用本地静态服务即可：
> ```bash
> cd jianci
> python -m http.server 8000     # 然后访问 http://localhost:8000
> ```

## 记忆曲线怎么工作

复习间隔参考艾宾浩斯遗忘曲线：**1 → 2 → 4 → 7 → 15 → 30 → 60 → 120 天**。
每个词有一个「阶段（stage）」，stage 就是它已经成功复习过几轮，`due` 是下次该复习的日期。

每次看完一个词，你给它一个评价，间隔这样变：

| 评价 | 快捷键 | 阶段变化 | 结果 |
| --- | --- | --- | --- |
| **熟练** | `1` | 阶段 +1 | 间隔拉长，越背越久才见面 |
| **一般** | `2` | 阶段不变 | 按当前间隔再来一轮 |
| **忘记** | `3` | 阶段 −2 | 退回前面，且**本轮队列里稍后再出现一次** |

- 新词：选「熟练」直接进入阶段 1（2 天后复习）；选「一般 / 忘记」停在阶段 0（**明天必复习**）。
- 阶段 ≥ 5（间隔已到 30 天）记为**已掌握**。
- **打卡条件**三选一：任务全部完成（默认）/ 只需完成复习 / 手动打卡。

### 每天的任务怎么定

- **新词**：按「每日新词量」在当天首次打开时排好队列，多本词书轮流分配。**没学完的队列会自动顺延到第二天**，不会悄悄丢掉；当天学满配额后不会再追加，避免超额。
- **复习**：所有 `due ≤ 今天` 的词，按到期时间和阶段排序，默认最多 100 个（可调）。
- **填空**：用当天学过的词 + 当天答错的词出题，默认 10 题；答错的词退回上一个阶段，明天重新出现。

## 词库

内置三本，共 **303 词**，每条都包含：IPA 音标、词性、中文释义、**中英例句**、**1–3 个形近词 / 易混词（带一句区分提示）**、**1–3 个变形或派生词**。

| 词书 | 词条 | 侧重 |
| --- | --- | --- |
| 考研核心词汇 | 100 | 考研大纲高频，偏学术阅读与写作 |
| 六级核心词汇 | 100 | 六级真题高频，难度介于四级与考研之间 |
| 雅思核心词汇 | 103 | 雅思学术主题词 + 写作论证词，英式拼写优先 |

这 303 条**全部**能用例句挖空出填空题（已由 `tools/validate-data.cjs` 逐条验证）。

### 导入 txt 词表 / 自定义词书

「词书 → 导入自己的词书」支持两种方式：

1. **选 txt 文件**：点「选择 txt 文件」，或直接把文件**拖进虚线框**。编码自动识别（UTF-8 / GBK / UTF-16，带不带 BOM 都行），文件名默认作为词书名。
2. **粘贴文本**：把词表贴进输入框，点「导入粘贴内容」。

读取后先给出**预览**（识别到多少个词、前几个长什么样），点「确认导入」才真正写入，点「取消」什么都不留。

每行一个词，下面这些写法都能认：

```
abandon 放弃；抛弃
abundant, 丰富的
resilience；韧性
mitigate v. 减轻；缓解
articulate v. /ɑːˈtɪkjuleɪt/ 清晰地表达
ubiquitous /juːˈbɪkwɪtəs/
in terms of 就……而言
1. ubiquitous 无处不在的
```

会自动去掉行首序号、把 `/.../` 识别成音标（不会当成释义）、识别 `v.` 这类词性、支持 `, ， ; ； 、 Tab | : ： / —` 分隔符和多词短语，并自动去掉重复词。

### 导入的词怎么考

词汇来源不同，题型会自动降级，保证**多大的词表都能背、也能考**：

| 词条里有什么 | 出什么题 |
| --- | --- |
| 有例句 | **例句挖空**：填单词，大小写、常见词形都算对 |
| 只有中文释义 | **看释义选单词**：4 选 1 |
| 只有音标（大纲词表常见） | **看音标拼写**：给首字母和字母数 |
| 三样都没有 | 只背不考；这类词不计入当日填空目标，**不会卡住打卡** |

## 词根词缀怎么用

内置 **363 条**词素：**75 个前缀 + 219 个词根 + 69 个后缀**（`js/data/morph-*.js`），每条都带中文含义和例词。

**卡片上**：翻面后，能拆的词会多一块「词根词缀」，例如

> `conduct` → **con-**（共同；一起；加强） + **duc / duct**（引导；lead）
> `biography` → **bio**（生命） + **graph**（写；画） + **-y**（形容词后缀：多…的）

拆不出词素时这一块**不显示**，不会硬凑。下面还有一行「同根词」，列出你词库里同样用到这些词素的词（如 `produce / introduce / reduce`），可以用一条词根串起一串词。

**词根页**：5 个标签里的「词根」，可以

- 搜拼写（`duc`、`spect`）、搜中文含义（`看`、`引导`、`不`）、搜例词（`transport`）；
- 按 前缀 / 词根 / 后缀 筛选；
- 每张卡片显示该词素在你**当前词书**里命中了哪些词，学过的词高亮，按命中数量排序——先看「最划算」的词根。

拆解是按拼写做的最优匹配，**不是词源学考证**，所以界面上措辞是「能认出…」而不是「本词来自…」。状态分三种：

| 情况 | 卡片上的说法 |
| --- | --- |
| 字母全被词素覆盖 | 完整拆解 |
| 只认出一部分 | 「能认出 X、Y，剩下 Z 没有对应词素，仅供参考」 |
| 一个都认不出 | 不显示这一块 |

对**导入的 txt 词表**一样会自动拆解——词根词缀不需要词条里预先写数据。

## 自测

```bash
node tools/validate-data.cjs   # 词库：字段、唯一性、例句可挖空率
node tools/validate-morph.cjs  # 词根词缀：字段、id 唯一、重复词形，以及在 303 词上的拆解率
node tools/validate-css.cjs    # 样式：有没有「用了却没写样式」的 class
node tools/test-engine.cjs     # 引擎：分配 / 复习 / 打卡 / 阶段推进 / 词根拆解 / 导入导出 / 边界
node tools/test-dom.cjs        # 界面：真加载页面并模拟点击走完整流程（需 npm i jsdom）
```

当前结果：词库 **303 / 303** 通过；引擎 **148 / 148** 通过；界面 **146 / 146** 通过，无运行时报错。
`test-dom.cjs` 需要 jsdom，默认从 `%TEMP%\jc_domtest\node_modules` 读取，也可用 `JSDOM_PATH` 指定；未安装时会自动跳过而不是失败。

拆解覆盖率（`validate-morph.cjs` 会打印）：303 个内置词里 **208 个能拆出词素（69%）**，其中 116 个是完整拆解。覆盖率不是越高越好——另有 30 个词（`moreover`、`poverty`、`enormous`…）因为拼写撞上词素但词源对不上，被引擎**主动放弃拆解**，宁可空着也不给错提示。

## 设计取舍

- **零依赖单页**：只有原生 HTML/CSS/JS + `localStorage`，没有框架、没有构建步骤、没有网络请求，拷贝整个文件夹就能离线用。
- **算法与界面分离**：`srs.js` 是纯函数（日期、阶段、出题、判分），因此可以在 Node 里被完整测试；`morph.js` 同样是不碰 DOM 的纯函数（题库 → 拆解结果）；`store.js` 只负责状态与计划；`app.js` 只负责渲染。
- **拆不出来就说拆不出来**：词根词缀是「按拼写最优匹配」的辅助记忆，不是词源考证。引擎宁可放弃（全库 69% 能拆，另有 30 个词被主动拉黑），也不给 `person → son`、`month → mon` 这类看着热闹其实错的提示；部分拆解时界面会明说「剩下 X 没有对应词素，仅供参考」。
- **排好队就不丢**：新词队列、待复习词都是持久化的状态而不是临时变量，中途关掉网页也不会漏掉没背完的词。
- **容错**：`localStorage` 不可用（隐私模式 / `file://` 受限）时自动退化为内存存储；存档损坏时自动回到默认设置；容量超限时静默跳过写入，不阻塞学习。

## 已知限制

- 内置词库是 303 个**精选词**，不是完整大纲词表；要背全量词表请用「导入自己的词书」。
- 词根词缀拆解是按拼写做的匹配，个别词会给不出提示或拆得不完整（长词、拼写演变大的词尤其明显），当参考而不是定论。
- 朗读使用浏览器自带 TTS（`speechSynthesis`），不同系统的音色和可用性不同。
- 记录存在 localStorage：换浏览器、清缓存、换设备都会看不到，请用导出 / 导入迁移。
- 朗读固定使用美式发音（`en-US`），在「设置」里可以关掉自动发音，改用卡片上的 🔊 手动听。
